AI Help Desk Triage Agent

It reads an IT ticket the way an employee wrote it, works out what the problem is and how urgent it is, finds the right knowledge base article, and drafts a reply for a human agent to check. It runs entirely on free, local AI models.

Real tickets, real output

Each example below is the agent's actual output, chosen to show a different situation: impact buried in the text, a vague subject, two problems in one ticket, and a misclassification the agent caught itself.

    How it got to 97%

    Share of tickets with both the problem type and the priority correct, on 200 held-out tickets. Each version changed one thing based on what the previous evaluation showed. The last line is a fresh set generated after tuning ended, so it measures tickets no version had seen.
